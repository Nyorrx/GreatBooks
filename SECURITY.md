# Security Policy

## Supported Versions

This project is a static digital academic portfolio. Only the latest release on the primary `main` branch is actively maintained.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability, sensitive data exposure, or dependency risk within this repository:

1. **Do not create a public issue or discussion.**
2. Report the vulnerability privately via **GitHub Security Advisories** (under the "Security" tab of the repository) or contact the project maintainer directly.
3. Provide a clear description of the finding, reproduction steps, and any potential impact.

Maintainers will review the submission promptly, assess the risk, and issue a patch or dependency update as appropriate.

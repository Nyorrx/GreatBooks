# Audio Repository: My Literary Journey

This directory contains the custom audio soundtrack for the Navigator's Chart Table.

## Folder Structure

```text
public/
└── audio/
    ├── islands/
    │   ├── The Odyssey Soundtrack (2026) by Ludwig Göransson - Echoes of the Underworld.mp3
    │   └── soundtrack.mp3 (compatibility fallback)

```

## Active Soundtrack

The literary atlas uses the unified soundtrack placed in `public/audio/islands/`:

- **Title**: The Odyssey Soundtrack (2026)
- **Subtitle**: Echoes of the Underworld
- **Composer**: Ludwig Göransson
- **Filename**: `The Odyssey Soundtrack (2026) by Ludwig Göransson - Echoes of the Underworld.mp3`
- **Served URL**: `/audio/islands/The%20Odyssey%20Soundtrack%20(2026)%20by%20Ludwig%20G%C3%B6ransson%20-%20Echoes%20of%20the%20Underworld.mp3`

The soundtrack plays continuously across all literary realms and can be controlled directly from both the Navigator's Chart overview and every island Field Journal.
